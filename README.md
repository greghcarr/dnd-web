# dnd-web

A full-screen 2D top-down RPG-style viewer for D&D combat replays generated by the [dnd-srd-engine](../dnd-srd-engine). It renders the engine's seed-deterministic "combat fuzz" battles as a tiled, Pokemon-style arena with character tokens, alongside a transport bar (skip to start, step back, play, step forward, skip to end), a human-readable battle narration console, and a raw event inspector.

This is a replay viewer first; player control comes later.

## Run

```
cd "../dnd-srd-engine" && npm install   # one time, engine deps
cd "../dnd-web" && npm install
npm run dev
```

Open http://localhost:5174.

## How it works

The engine computes combat abstractly, with no positions. dnd-web synthesizes a battlefield: each team is placed in facing ranks on a grid, and tokens reflect the engine state at the current replay cursor (HP, downed, active turn, conditions). Stepping the transport scrubs the committed event log; the narration console turns events into sentences like "Aria the Barbarian Human hits Bran for 8 bludgeoning with a greatclub."
