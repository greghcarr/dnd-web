# dnd-web

A full-screen 2D top-down RPG-style viewer for D&D combat replays generated by the sibling [dnd-srd-engine](../dnd-srd-engine). It renders the engine's seed-deterministic "combat fuzz" battles as a tiled, Pokemon-style arena, alongside transport controls, a human-readable battle log, and a raw event inspector. It is a replay viewer first; player control comes later.

Status: early development, `0.1.0-pre-alpha`.

## Quick start

dnd-web consumes the engine from source, so install the engine's deps first:

```
cd "../dnd-srd-engine" && npm install
cd "../dnd-web" && npm install
npm run dev
```

Open http://localhost:5174: two combatants on a fenced grass arena, paused at the start, with a side panel of controls. Press play, or scrub the transport. More in [docs/getting-started.md](docs/getting-started.md).

## How it works (in one breath)

The engine computes combat abstractly, with no positions. dnd-web synthesizes a battlefield, places each team in facing ranks, and drives every panel from a single replay cursor over the committed event log. Stepping the transport scrubs the log; the battle log turns events into sentences like "Aria the Barbarian Human hits Bran for 8 bludgeoning with a greatclub." Full picture: [docs/architecture.md](docs/architecture.md).
